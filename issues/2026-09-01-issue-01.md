## The one sentence

The Marc Lou stack that used to sell *speed-to-launch kits* is now a *recurring verification + analytics* stack. If you are still shipping another boilerplate this week, you are selling last year's product to this year's buyer.

**Steal:** recurring products that sit *on top of* an audience beat one-time kits. TrustMRR (take-rate / marketplace) + DataFast (attribution SaaS) are ~83% of the month.

**Do not steal:** another Next.js starter or "learn to code in weeks" course. Those two lines together are $7K vs $68K for the two recurring tools.

**This-week experiment (2 hours):** pick *one* metric your existing audience already trusts (revenue screenshot, waitlist count, churn, time-to-first-payment). Productize *verification or dashboarding of that metric*, not a new kit. Price it monthly.

Free preview, popular plan **$49/mo**, Stripe to the creator. Claim: 23,000+ episodes/posts indexed. **Postiz** (case study, cited 2026-09-01): open-source scheduler repositioned for AI agents; founder Nevo publicly cited **$145K MRR**. Playbook was GitHub stars → cloud conversion → MCP/CLI so agents can post. Source: [Superframeworks / Postiz](https://superframeworks.com/case-study/postiz).

Angle: sell to *agents* as the new customer, not only humans. If you have a CLI, ship an MCP this month.
